# Photo de Basile (mascotte)

Dépose ici le portrait détouré de Basile sous **exactement** ce nom :

    public/assets/basile/basile.png

- Fond transparent (PNG) recommandé.
- Format plutôt vertical / carré, sujet centré.
- Le jeu l'utilise comme mascotte (accueil, menu, découverte, mini-jeux,
  récompense, espace parent).

Si le fichier est absent, le composant `BasileMascot` ne s'affiche pas et le
jeu continue normalement (un message discret est écrit dans la console).
