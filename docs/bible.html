Le Monde de Basile — Bible du projet

Documentation unique et autonome du jeu local Les aventures des Alphas de Basile : application React + TypeScript + Vite conçue pour un enfant de maternelle, jouée sur iPad Pro en paysage, sans réseau.

React 18 · TypeScript · Vite 5 100 % hors-ligne Aucun backend 82 fichiers dans src/

01 Vision & principes

Un espace de jeu calme et bienveillant pour apprendre à reconnaître les lettres et les mots, sans pression. La bible fixe d'abord les règles non négociables : tout le reste du document en découle.

Objectif

Faire découvrir les Alphas (personnages qui portent le son des lettres), le prénom BASILE, puis des mots simples et courants du quotidien, à travers de grandes activités libres. Le jeu est destiné à un jeune enfant, souvent seul devant la tablette, parfois accompagné d'un adulte.

Principes non négociables

Règles du produit — à respecter par toute évolution
  • Aucun backend, aucune API distante, aucune donnée envoyée. Le jeu est 100 % hors-ligne.
  • Aucune pénalité, aucun chronomètre, aucun score anxiogène. Une mauvaise réponse est toujours douce.
  • Sauvegardes additives et non destructives : on n'écrase jamais une donnée existante.
  • Une seule piste audio à la fois (voix) : jamais de superposition.
  • Respect de prefers-reduced-motion pour toutes les animations.
  • Cible tactile : iPad Pro en paysage. Zones de dépôt généreuses, pas de précision fine.
  • Pas d'emoji utilisé pour remplacer une illustration existante.

Ce que la bible couvre

  • Le code : architecture, dossiers, composants, données, utilitaires.
  • Le contenu : Alphas, mots, lettres, activités, sons.
  • Les sauvegardes locales et leurs règles de migration.
  • Les procédures : lancer, tester, vérifier, étendre.
Les README de dossiers (public/audio/…, scripts/README-voices.md) restent des annexes de détail. Cette bible les rassemble et fait autorité.

02 Démarrage rapide

Installer, lancer, et jouer sur l'iPad.

Prérequis

  • Node.js 18+ et npm.
  • Python 3 uniquement pour les scripts d'assets et de bruitages (optionnel).
  • Un Mac pour la génération de voix via say (optionnel).

Lancer en local

npm install
npm run dev         # http://localhost:5173

Jouer sur l'iPad Pro (Wi-Fi local)

npm run dev -- --host
# le terminal affiche http://192.168.1.x:5173
# ouvrir cette adresse dans Safari sur l'iPad (même réseau)

Pour un rendu plus stable sur tablette, utiliser le build de production :

npm run build
npm run preview     # déjà exposé sur le réseau (--host)
Autoplay iOS Safari mobile bloque la lecture audio avant une interaction. Le premier tap déverrouille l'audio via primeAudio() (voir src/lib/audio.ts).

03 Architecture applicative

Une application React mono-page dont la navigation est un simple état local. Aucun routeur.

Navigation

L'ensemble des écrans est piloté par un unique état screen dans src/App.tsx (type Screen), complété par quelques états annexes (universeId, stats, lastResult, discoveryTarget). Chaque écran reçoit ses props et des callbacks de navigation. 

type Screen =
  | "home" | "discovery" | "universes" | "game" | "reward"
  | "parent" | "boss" | "nurserie" | "jardin-magique"
  | "atelier" | "pirates" | "cabane" | "album"

Flux d'écrans (simplifié)

Accueil (home)
 ├─ Le Jardin des Alphas ──► discovery ──► universes ──► game ──► reward
 │                                              └────► album
 │                                              └────► boss (boss du prénom)
 ├─ Nurserie des dragons ──► nurserie
 ├─ Jardin magique ───────► jardin-magique
 ├─ Atelier ──────────────► atelier
 ├─ Port des Pirates ─────► pirates
 └─ Ma Cabane ────────────► cabane

Espace Parent ────────────► parent   (accessible depuis l'accueil)

Moteur pédagogique commun

Les huit univers partagent le même moteur : une manche pose une consigne, affiche 2 ou 3 propositions, valide la bonne réponse et enchaîne. Chaque univers n'apporte qu'un décor (src/components/scenes/) et un plateau (src/components/boards/, contrat BoardProps). Le registre src/components/universes/registry.tsx fait le lien entre un UniverseId et son couple décor/plateau. 

// Déclarer un univers
src/data/universes.ts        -> UNIVERSES, correctSfx / accentSfx
src/components/scenes/…      -> décor
src/components/boards/…      -> plateau (props BoardProps)
src/components/universes/registry.tsx -> association id -> (Scene, Board)

Rendu et style

  • Point d'entrée : index.html → src/main.tsx → App.tsx.
  • Un unique feuillet src/styles.css (~6400 lignes), organisé par commentaires de section.
  • Animations CSS uniquement (transform / opacity).
  • Mascotte BasileMascot avec variantes hero, guide, sidekick, reward et humeurs idle/happy/celebrate.

Configuration

vite.config.tsPlugin React + middleware MIME audio/aiff (compat Safari) ; serveurs en --host.
tsconfig.jsonstrict, noUnusedLocals, noUnusedParameters, noFallthroughCasesInSwitch.
index.htmlMétadonnées web-app capable, favicon éclair en SVG inline, zoom désactivé.

05 Le Monde de Basile (portail)

L'accueil est un portail illustré vers six grandes activités. Le « Jardin des Alphas » ouvre le jeu pédagogique historique ; les cinq autres sont des espaces de jeu libres.

  • Décor original en SVG/CSS : jardin, soleil, nuages, cabane, chemin, fleurs, papillons, petit dragon endormi.
  • Données des cartes : src/data/activities.ts (ActivityId, ACTIVITIES).
  • Illustrations du portail : src/components/home/.
  • Navigation : selectActivity dans App.tsx, sans dépendance ajoutée.

Annonce orale des activités

  • Survol souris de 350 ms → annonce (sans boucle, annulée si la souris repart).
  • Sur iPad : deux touchers (le premier sélectionne et prononce, le second ouvre).
  • Bouton haut-parleur sur la carte pour réécouter.
  • Focus clavier : annonce au focus, ouverture par Entrée / Espace.
  • Les activités « bientôt » sont annonçables mais jamais ouvrables.

06 Les six activités

Chaque activité possède sa sauvegarde dédiée, ses bruitages et ses consignes. Aucune n'utilise de questionnaire sur les Alphas, sauf le Jardin des Alphas.

Le Jardin des Alphas Jouable

Porte d'entrée du moteur pédagogique : 8 univers + boss du prénom. Voir section 07 et 08.

Ma Cabane V1

Pièce 2D interactive. Lit en direct les collections des autres activités (étagère, coffre, cadres, vase). Décorations : murs, tapis, rideaux.

Le Port des Pirates V1

Carte maritime, 3 îles, 4 cachettes par île, trésors déterministes collectés dans « Mes trésors ».

L'Atelier de Basile V1

Construction par glisser-déposer (voiture, robot, fusée), choix de couleur, étagère de collection.

Le Jardin magique V1

Planter 3 graines dans 4 parcelles, arroser par étapes, récolter. Papillons, coccinelles.

La Nurserie des dragons V1

Nourrir, faire boire, caresser, jouer, endormir un bébé dragon. Trois jauges douces, aucune horloge.

Ambiguïtés pédagogiques assumées Les variantes é/è/ê ne sont pas des lettres distinctes, et ch est un digramme : ils appartiennent au groupe special et ne sont jamais proposés par défaut. Le boss BASILE reste figé sur les six personnages du prénom.

Par défaut & espace Parent

  • Au départ, seuls les six Alphas de BASILE sont actifs ; deux sont découverts (début de partie).
  • Aucune nouveauté n'est débloquée automatiquement.
  • L'espace Parent permet d'activer/désactiver, débloquer, ordonner la découverte, consulter les confusions fréquentes et réinitialiser les progrès (avec confirmation).
  • L'Album des Alphas (depuis « Choisis ton univers ») montre les Alphas découverts interactifs et les autres en silhouette.

Moteur commun

Les huit univers puisent dans les Alphas découverts ∩ actifs. Sélecteurs dans src/lib/catalogue.ts : playableAlphas, nextToDiscover, markDiscovered, setActive, unlockAlpha, moveInOrder, resetPedagogy.

Boss du prénom — « Le Mystère du prénom BASILE »

  1. Étape A — retrouver chaque Alpha et allumer sa pierre magique.
  2. Étape B — reconstituer B-A-S-I-L-E par tap tactile (jamais de clavier), avec trois niveaux d'aide : debutant / intermediaire / avance.
  3. Étape C — château qui s'ouvre, dragon qui s'envole, confettis, médaille enregistrée.

Rejouable à volonté. La vérification de l'image de Madame i est réelle (aucune substitution). Récompense persistée dans alphas-de-basile/boss/v1.

10 Les lettres vivantes (mission 2)

Des lettres-jouets que l'enfant peut toucher, déplacer et relâcher, qui réagissent et prononcent le nom de la lettre.

Notions volontairement séparées (src/data/letters.ts)

NotionRôleAudio
nameNom français de la lettre (ex. « bé »)lettre-* — joué
phonemeInformation pédagogique (ex. /b/)jamais joué
alphaId / alphaNameAlpha associé (correspondance validée)alpha-* conservé
Règle audio On ne réutilise JAMAIS l'audio d'un mot complet (mot-*, tresor-*) pour une lettre isolée. Un seul audio par caractère : lettre-a … lettre-z.

Progression

L'ordre commence par les lettres du prénom BASILE_LETTERS = ["b","a","s","i","l","e"], puis s'étend aux lettres du catalogue découvert (Alphas « letter » simples, digrammes et variantes exclus). Sélecteurs dans src/lib/letters.ts : availableLetters, firstLetterToy, pickAvailableLetter.

Interaction (src/components/InteractiveLetter.tsx)

  • Pointer Events unifiés (souris + tactile), position clammée aux bornes de l'écran.
  • Réactions : saut, dandinement (wobble), rotation (spin), atterrissage, puis retour au repos.
  • Toucher lit le nom de la lettre.
  • Intégrée notamment dans NurserieScreen.tsx (reactToLetter) et JardinMagiqueScreen.tsx (showGardenLetter).
Piège connu Ne jamais lire l'état de glissement depuis un état React dans un pointerup rapide : utiliser une ref synchrone (voir InteractiveLetter).

11 Jouer avec le mot (mission 3)

Mini-jeu facultatif, ouvert depuis la carte de découverte, où l'enfant reconstitue le mot en déplaçant des lettres. Jamais automatique, jamais obligatoire.

Accès

Un bouton « Jouer avec le mot » apparaît dans WordRevealCard uniquement pour un mot jouable (isPlayableWord). Le mini-jeu s'ouvre sur action : la fermeture automatique de la carte est suspendue pendant la partie, et l'enfant peut sortir à tout moment (retour à la carte).

Mots activés (src/lib/wordGame.ts)

PLAYABLE_WORD_IDS = WORDS.map(w => w.id) : tout le catalogue M1 est jouable (mots courts et longs, accents inclus). Deux mots proposés sont volontairement exclus car ils n'ont pas d'objet : ILE et OR.

Deux modes (src/components/WordPlayground.tsx)

ModeModèleLettresAide
Découverte (défaut) visible dans l'ordre, emplacements guidés (lettre fantôme) bouton « Aide » (place la prochaine lettre)
Défi doux masqué (« Voir le mot ») mélangées, emplacements neutres bouton « Recommencer » libre

Interaction

  • Toucher une lettre puis un emplacement, ou glisser-déposer (Pointer Events + elementFromPoint / [data-slot]).
  • Grandes zones de dépôt (tuile CSS --wg-tile), dimensionnées selon la longueur du mot.
  • Lettres répétées : identifiants uniques par occurrence (`${word}-${index}`).
  • Accents : caractère affiché conservé (É, Ê), lettre de base normalisée (NFD) pour l'audio.

Audio

  • Mot complet prononcé à l'ouverture et après réussite.
  • Toucher une lettre lit son nom (lettre-<base>).
  • Le mot n'est jamais épelé lettre à lettre.
Garde-fous Aucune pénalité, aucun chronomètre, aucun score. Le jeu ne peut pas interrompre la collecte d'un trésor, une récolte ou une construction : il vit à l'intérieur de la carte, après l'enregistrement de la récompense.

12 Audio & voix

Tout l'audio est local et généré automatiquement. Aucun service, aucune API, aucun modèle embarqué dans l'application.

Manifeste central

src/data/audioManifest.ts est la source de vérité : chaque entrée a un id, un kind (voice ou sfx) et un label. Remplacer un son = écraser le WAV du même nom.

Voix143 fichiers · public/audio/fr/<id>.wav
Bruitages35 fichiers · public/audio/sfx/<id>.wav
Voix du catalogue étendudérivées automatiquement de alphas.ts (24 Alphas × 2)
ExtensionsVOICE_EXT / SFX_EXT dans le manifeste

Familles de voix

Moteur de lecture (src/lib/audio.ts)

  • Anti-superposition : une seule consigne vocale jouée à la fois ; isVoicePlaying évite les relances inutiles.
  • Volumes distincts : DEFAULT_VOICE_VOLUME (1) et DEFAULT_SFX_VOLUME (0.5), réglables via setVoiceVolume / setSfxVolume.
  • Autoplay iOS : primeAudio() au premier tap / touche.
  • API : playVoice, stopVoice, playSfx, playVoiceAwait, probeAudio, diagnoseAudio.

Règles de persistance

Additivité Une nouvelle fonctionnalité écrit dans sa propre clé ; elle ne réécrit jamais les clés existantes. La Cabane, par exemple, ne stocke que ses décorations et lit les collections des autres.
  • Chaque load* désérialise puis sanitize : types vérifiés, valeurs bornées (ex. jauges 0..100, index de décoration clammés).
  • Les erreurs de lecture/écriture sont journalisées en console.debug et ne bloquent jamais le jeu.
  • Migration rétro-compatible : dans stats, l'ancien champ numérique decouverte est converti en liste decouverts ; ordre est complété/filtré selon le catalogue connu.
  • Chaque domaine expose aussi un reset* (souvent via l'espace Parent, avec confirmation).

17 Conventions de code

Quelques règles simples pour toute contribution future.

  • TypeScript strict : strict, noUnusedLocals, noUnusedParameters. Pas de any implicite.
  • Pas de commentaires ajoutés dans le code sauf nécessité (le style existant en contient peu, uniquement pour expliquer une décision).
  • Contenu déclaratif : les listes (Alphas, mots, lettres, activités, univers, trésors) vivent dans src/data/ ; la logique dans src/lib/.
  • Persistance additive : nouvelle clé dédiée, jamais de réécriture destructive ; sanitize à la lecture.
  • Pointer Events et refs synchrones pour le glisser-déposer (ne pas lire l'état React dans un pointerup rapide).
  • Animations CSS uniquement, respectant prefers-reduced-motion.
  • Local d'abord : aucun appel réseau, aucune dépendance ajoutée sans raison forte.
  • Nommage : fichiers de composants en PascalCase, identifiants de contenu en français (cohérent avec l'existant).

18 Guides d'extension

Recettes pour les évolutions les plus courantes.

Ajouter un univers pédagogique

  1. Créer un décor dans src/components/scenes/.
  2. Créer un plateau dans src/components/boards/ (props BoardProps).
  3. Déclarer le monde dans src/data/universes.ts (UniverseId, UNIVERSES, correctSfx/accentSfx).
  4. Ajouter l'entrée dans src/components/universes/registry.tsx.

Le moteur (manches, score, consignes, progression) est réutilisé automatiquement.

Ajouter une activité du portail

  1. Ajouter son ActivityId et son entrée dans src/data/activities.ts.
  2. Créer l'écran src/components/<Nom>Screen.tsx et l'ajouter au type Screen + au rendu dans App.tsx.
  3. Créer une sauvegarde dédiée dans src/lib/ (clé alphas-de-basile/<nom>/v1, sanitize à la lecture).
  4. Ajouter les voix (activite-*) et bruitages au manifeste + à voice-lines.json.
  5. Créer la carte du portail dans src/components/home/.

Ajouter un mot (mission 1)

  1. Ajouter l'entrée dans WORDS (src/data/words.ts) : id, label accentué, voice.
  2. Ajouter l'illustration dans WordArt.tsx.
  3. Réutiliser un audio existant ou ajouter une entrée mot-* (manifeste + voice-lines.json), puis générer.
  4. Brancher éventuellement un mapping objet → mot.

Ajouter une lettre jouable

Couvert automatiquement pour a–z dès qu'une entrée LETTER_NAMES et un audio lettre-<x> existent. Pour un nouveau graphème (digramme, variante), l'étendre explicitement.

Ajouter un son (voix ou bruitage)

  1. Déclarer l'entrée dans src/data/audioManifest.ts (kind = voice ou sfx).
  2. Pour une voix : ajouter le texte + le rôle dans scripts/voice-lines.json.
  3. Générer : npm run voices ou npm run voices:neural / npm run sfx.
  4. Vérifier : npm run voices:check.

20 Dépannage / FAQ

Le son ne démarre pas sur iPad

Safari bloque l'autoplay avant interaction. Toucher l'écran une fois (le jeu appelle primeAudio()).

Un fichier audio manque

Le jeu reste jouable ; l'écran Parent affiche le statut présent/absent. Regénérer via npm run voices / npm run sfx, puis npm run voices:check.

Une image d'Alpha ne s'affiche pas

Vérifier public/assets/alphas/ et lancer npm run alphas. En l'absence d'image optimisée, le jeu utilise l'original ; en l'absence totale, une carte « image à venir » s'affiche.

La mascotte Basile n'apparaît pas

Le fichier public/assets/basile/basile.png est probablement absent. Un message discret est écrit dans la console ; le jeu continue normalement.

Repartir de zéro (progrès d'un enfant)

Utiliser les réinitialisations de l'espace Parent (avec confirmation). Pour tout effacer : supprimer les clés alphas-de-basile/* dans le stockage local du navigateur.

Où modifier les textes prononcés ?

Dans scripts/voice-lines.json (texte + rôle), en cohérence avec les ids de src/data/audioManifest.ts.

Une animation saccade ou est trop forte

Le jeu respecte prefers-reduced-motion. Activer « Réduire les animations » dans les réglages d'accessibilité de l'appareil réduit les mouvements.
